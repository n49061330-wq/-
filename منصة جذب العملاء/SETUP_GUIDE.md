# دليل إعداد منصة جذب العملاء الذكية

## ✅ خطوات الإعداد والربط

### 1. إعداد N8N Workflow

#### أ) استيراد الـ Workflow
1. في لوحة تحكم N8N، انقر على **"Import"**
2. انسخ محتوى ملف `n8n_workflow.json` بالكامل والصقه
3. تأكد من أن الـ Workflow تم استيراده بنجاح
4. لا تنسى **تفعيل (Active) الـ Workflow** قبل الاستخدام

#### ب) اختبار الـ Webhook
بعد استيراد الـ Workflow:
- سيظهر لك رابط الـ Webhook في الـ node الأول
- الرابط الافتراضي: `https://your-n8n-instance.cloud/webhook/lead-generation`
- احفظ هذا الرابط - ستحتاجه في الخطوة التالية

---

### 2. إعداد مفاتيح API المطلوبة

#### أ) Google Search API و Custom Search Engine
1. اذهب إلى [Google Cloud Console](https://console.cloud.google.com/)
2. أنشئ مشروع جديد أو افتح موجود
3. فعّل **Custom Search API**
4. أنشئ Custom Search Engine على [cse.google.com](https://cse.google.com/)
   - اختر البحث في جميع المواقع
   - احفظ معرف الـ CX الخاص بك
5. انسخ:
   - **API Key**: من Google Cloud Console
   - **CX**: من Custom Search Engine

#### ب) Gemini API
1. اذهب إلى [Google AI Studio](https://aistudio.google.com/)
2. انقر على **"Get API Key"** 
3. اختر مشروعك الموجود أو أنشئ جديد
4. انسخ الـ **API Key**

#### ج) N8N Webhook URL
- الرابط الذي حصلت عليه من الخطوة 1ب

---

### 3. إدخال المفاتيح في التطبيق

1. افتح التطبيق في المتصفح
2. انقر على زر **⚙️ الإعدادات** (أعلى اليمين)
3. ملء الحقول:
   ```
   🔗 رابط Webhook N8N:
   https://your-n8n-instance.cloud/webhook/lead-generation
   
   🔑 مفتاح Google API:
   YOUR_GOOGLE_API_KEY
   
   🔎 معرف محرك البحث (CX):
   YOUR_CX_ID
   
   🤖 مفتاح Gemini:
   YOUR_GEMINI_API_KEY
   
   💬 قالب الرسالة التسويقية:
   (يمكنك تخصيصه)
   ```
4. انقر على **حفظ الإعدادات**

---

### 4. اختبار النظام

#### المرحلة 1: اختبار في وضع Demo
1. تأكد من تفعيل **وضع التجريب** (Demo Mode)
2. اختر نشاط ومدينة
3. انقر على **🔍 بدء البحث**
4. يجب أن ترى بيانات تجريبية بعد ثانيتين

#### المرحلة 2: اختبار الاتصال الحقيقي
1. قم بإلغاء تفعيل **وضع التجريب**
2. اختر نشاط ومدينة وعدد العملاء
3. انقر على **🔍 بدء البحث**
4. سيتم:
   - البحث عن شركات باستخدام Google Search
   - استخراج أرقام الهاتف
   - توليد رسائل تسويقية بـ Gemini
   - عرض النتائج في الجدول

## 🔧 ماذا يحدث في الخلفية؟

### تدفق البيانات:
```
التطبيق (app.js)
    ↓
N8N Webhook ← يستقبل البيانات
    ↓
Google Search API ← يبحث عن الشركات
    ↓
استخراج أرقام الهاتف ← من نتائج البحث
    ↓
Gemini AI Writer ← يكتب رسالة مخصصة
    ↓
معالجة الاستجابة ← دمج جميع البيانات
    ↓
التطبيق ← يعرض النتائج في الجدول
```

---

## ⚠️ حل المشاكل الشائعة

### المشكلة: "خطأ في الاتصال بـ Webhook"
**الحل:**
- تأكد من تفعيل الـ Workflow في N8N
- تحقق من صحة الرابط (ليس هناك مسافات)
- افتح الـ Browser Console (F12) لرؤية رسالة الخطأ الدقيقة

### المشكلة: "عدم ظهور أي نتائج"
**الحل:**
- تحقق من أن جميع مفاتيح API صحيحة
- في N8N، افتح الـ Workflow وانظر إلى آخر تنفيذ
- تأكد من أن Google API الخاص بك لم يتجاوز الحد المسموح (300 طلب/يوم مجاني)

### المشكلة: "رسائل مختصرة أو غير صحيحة"
**الحل:**
- تحقق من قالب الرسالة في الإعدادات
- تأكد من أن Gemini API يعمل بشكل صحيح
- جرب طلب واحد فقط أولاً لرؤية الاستجابة الكاملة

## 📊 الميزات المتاحة

✅ إرسال رسائل واتساب مباشرة

✅ ملاحظات وتعليقات على كل عميل

## 💡 نصائح لأفضل النتائج

1. **استخدم كلمات بحثية دقيقة**: بدلاً من "مطاعم"، اكتب "مطاعم عائلية برياض"
2. **حدد عدد عملاء معقول**: 5-10 في البداية (الحد الأقصى 100)
3. **تخصيص الرسالة**: عدّل قالب الرسالة حسب خدماتك
4. **متابعة النتائج**: حدّث حالة العملاء بعد التواصل معهم
