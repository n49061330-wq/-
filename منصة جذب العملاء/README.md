# منصة جذب العملاء الذكية - Lead Hunter Platform

## 📋 نظرة عامة

منصة متكاملة لاستكشاف وتتبع العملاء المحتملين باستخدام الذكاء الاصطناعي.

**الميزات الرئيسية:**
- 🔍 البحث الذكي عن العملاء حسب النشاط والمدينة
- 🤖 توليد رسائل تسويقية مخصصة بـ Gemini AI
- 📞 استخراج أرقام الهاتف تلقائياً
- 📊 لوحة تحكم بإحصائيات شاملة
- 💬 إرسال رسائل واتساب مباشرة
- 📁 تصدير البيانات إلى CSV

## 🏗️ البنية التقنية

### المكونات الرئيسية:

```
┌─────────────────────────────────────────────────────────────┐
```

## 🚀 سريع البدء

### خطوة 1: الإعداد الأولي
```bash
# انسخ ملف الإعدادات المثال
cp config.example.json config.json

# أدخل مفاتيح API الخاصة بك في config.json
```

### خطوة 2: إعداد N8N
1. اذهب إلى لوحة تحكم N8N
2. استورد `n8n_workflow.json`
3. فعّل الـ Workflow (اضغط على المفتاح الأخضر)

### خطوة 3: بدء البحث
1. افتح التطبيق
2. أدخل مفاتيح API في الإعدادات
3. اختر نشاط ومدينة
4. اضغط "بدء البحث"

## 📊 مثال على سير البحث الكامل

### الخطوة 1: المستخدم يبدأ البحث
```
المستخدم يدخل:
- النشاط: "مطاعم"
- المدينة: "جدة"
- الحد الأقصى: 5
```

### الخطوة 2: التطبيق يرسل الطلب
```javascript
POST /webhook/lead-generation

{
  "google_search_api_key": "AIzaSy...",
  "google_search_cx": "123456:abc",
  "gemini_api_key": "AIzaSy...",
  "keyword": "مطاعم",
  "city": "جدة",
  "lead_limit": 5,
  "prompt_template": "..."
}
```

### الخطوة 3: N8N يعالج البيانات
```
1. Google Search: يبحث عن "مطاعم في جدة السعودية"
   ↓
   ← النتيجة: 5 نتائج بعناوين ووصفات

2. Extract Phone: يستخرج أرقام الهاتف
   ↓
   ← 4 أرقام موجودة، 1 غير متاح

3. Gemini AI: يكتب رسالة لكل شركة
   ↓
   ← 5 رسائل مخصصة بالعربية

4. Process Response: يدمج البيانات
   ↓
   ← JSON مع كل البيانات مجمعة

5. Respond: ترسل الاستجابة للتطبيق
```

### الخطوة 4: التطبيق يعرض النتائج
```
✅ تم العثور على 5 عملاء محتملين
- يعرضها في الجدول
- يحفظها في LocalStorage
- يحدث الإحصائيات
```

## ⚙️ إعدادات متقدمة

### تخصيص قالب الرسالة

اذهب إلى الإعدادات وعدّل:
```
اكتب رسالة تسويقية مخصصة بالعربية...
[معدّل النصوص هنا]
```

### المتغيرات المتاحة في الرسالة:
- `[NAME]`: اسم الشركة
- `[CITY]`: اسم المدينة
- `[ACTIVITY]`: نوع النشاط

### مثال:
```
السلام عليكم فريق [NAME]، نقدر ريادتكم في مجال [ACTIVITY] بمدينة [CITY]...
```

## 🐛 استكشاف الأخطاء

### مشكلة: لا شيء يظهر
**الحل:**
```javascript
// افتح Developer Console (F12)
// انظر إلى الأخطاء:
console.log('Check Network tab for failed requests');
console.log('Check Application > LocalStorage');
```

### مشكلة: رسائل مختصرة
**السبب:**
- Gemini API قد لا يعمل
- قالب الرسالة غير صحيح

**الحل:**
- تحقق من مفتاح Gemini في الإعدادات
- عدّل قالب الرسالة

### مشكلة: أرقام هاتف غير صحيحة
**السبب:**
- البحث لم يجد أرقام صحيحة
- الموقع لا يحتوي على أرقام

**الحل:**
- جرّب كلمات بحثية مختلفة
- قلل عدد النتائج (5 بدلاً من 10)

## 🔒 الأمان

### البيانات الحساسة:
- ✅ المفاتيح تُخزن في LocalStorage (يجب أن يكون آمناً)
- ✅ البيانات لا تُرسل إلى جهات خارجية غير N8N
- ✅ استخدم HTTPS دائماً

### نصائح الأمان:
1. لا تشارك مفاتيح API مع أحد
2. قم بتحديث المفاتيح بشكل دوري
3. راقب استخدام API في Google Cloud Console
